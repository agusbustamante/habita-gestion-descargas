# Habita Gestión

Aplicación para Windows de 64 bits para organizar casas, servicios, alquileres y pagos en tu computadora.

## Descargar

**[Descargar la última versión](https://github.com/agusbustamante/habita-gestion-descargas/releases/latest)**

Abrí la publicación y descargá el archivo `.exe`. Ejecutalo y seguí los pasos del instalador. No necesitás instalar Node.js ni tener una cuenta de GitHub.

Si tenés una versión anterior a 1.7.2, instalá una vez 1.7.2 o posterior para activar las actualizaciones. Después Habita buscará las nuevas versiones desde la aplicación y te dejará elegir cuándo reiniciar para instalarlas.

## Datos y actualizaciones

- Las casas, contratos y pagos quedan guardados en cada PC. Este canal no incluye datos personales ni los sincroniza entre computadoras.
- Este repositorio contiene únicamente instaladores, blockmaps y manifiestos firmados. El proyecto se conserva en un repositorio privado.
- Habita comprueba la firma propia de las actualizaciones antes de instalarlas. Windows puede mostrar «Editor desconocido» porque no se utiliza un certificado comercial.
- La aplicación incluye una demostración con datos ficticios, un recorrido paso a paso y un manual interactivo.
